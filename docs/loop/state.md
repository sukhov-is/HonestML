# HonestML Loop — гроссбух

Строка на раунд и фаза пункта; фазу подтверждает матрица дизайн-пакета — реестры навигация,
свидетельство только матрица. Строки пишет `ops/loop/ledger.py` — он считает номер раунда, ставит
строку в нужное место таблицы и держит лимиты заметок. Полную хронику несут
`docs/implementation/changelog.md` и дизайн-пакет; здесь — статус-факты и указатели.
