# ADR-0001: Слои и направление зависимостей

Статус: Accepted (2025-11-02)

## Решение

- `billing/core/` — чистая бизнес-логика: модели и расчёты. НЕ импортирует
  `billing/storage/` и `billing/cli.py`.
- `billing/storage/` — SQLite-хранилище и экспорт; может импортировать core.
- `billing/cli.py` — точка входа, связывает слои.

## Последствия

Расчёты тестируются без БД; замена хранилища не трогает ядро.
