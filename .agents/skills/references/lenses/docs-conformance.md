# Направление: Код ↔ документация

## Чартер

Проверяет, что **документация и код говорят одно и то же**. Механика —
факт-чекинг: из доков извлекаются дискретные **проверяемые утверждения**,
каждое сверяется с кодом. Не твоё: качество самих доков (полнота, стиль) —
только Info-находки попутно; нарушение архитектурного правила из ADR
(→ архитектура; твоё — когда ADR **описывает** механизм, а код делает иначе).

Важно: расхождение — симптом с двумя причинами. Для каждой находки скажи,
что вероятнее устарело — **док или код** (по git-датам, по тому, на что
ссылаются тесты). Это меняет лекарство: обновить док ≠ чинить код.

## Чек-лист

1. Собери корпус: README, CLAUDE.md/AGENTS.md, ADR, docs/architecture,
   docs/guide и docs/api.md, docstrings публичных API, CHANGELOG (срез из
   фазы 0 — карта документации).
2. Извлеки утверждения — только проверяемые: «метрика выбора считается по OOF»,
   «опция Z по умолчанию выключена», «дефолт равен 0.01», «артефакт версии N
   грузится», «`honestml.core` не зависит от sklearn».
   Лозунги («код чистый и поддерживаемый») — не утверждения.
3. Проверь каждое по коду: подтверждено / расходится / непроверяемо.
   Приоритет — утверждениям со статусом «Accepted»/«актуально» в самих доках:
   расхождение в принятом ADR важнее, чем в черновике.
4. Отдельно: инструкции установки и запуска (выполнимы ли команды, существуют
   ли упомянутые файлы, пути, extras), примеры кода в доках — python-блоки
   `docs/quickstart.md` и `docs/guide/*.md` исполняет
   `tests/unit/test_docs_examples.py`; README, `docs/api.md`,
   `docs/correctness-guide.md`, ADR и docstrings не исполняет никто —
   устаревшая сигнатура живёт именно там.

## FP-контракт

**Жёсткие исключения**: расхождения в явно помеченных черновиках/Proposed;
исторические записи (changelog, Superseded ADR — они описывают прошлое);
вкусовые трактовки неоднозначных формулировок (неоднозначность — Info
«уточнить формулировку», не расхождение).

**Прецеденты**: док описывает намерение, код — текущий этап миграции, и это
помечено — TRADE-OFF; внутренние комментарии — не контракт (контракт — доки и
docstrings публичных API).

## Доказательства

Пара цитат: **строка дока** (файл:строка, дословно) + **код** (файл:строка),
который ей противоречит, + вердикт «вероятно устарел: док|код» с признаком.
Без обеих цитат находка не выдаётся.
