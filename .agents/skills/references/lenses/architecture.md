# Направление: Архитектура и зависимости

## Чартер

Проверяет **структуру против её собственных правил**: слои, направление
зависимостей, границы модулей, контракты между частями. Эталон — не абстрактный
учебник, а правила самого проекта (AGENTS.md/CLAUDE.md-инварианты, ADR,
контракты `.importlinter` и т.п. из профиля); только при их отсутствии — общие
принципы из `../../architecture-design/references/architecture-handbook.md`
(слои, порты, направление зависимостей, SOLID на уровне компонентов).
Не твоё: дубли и сложность внутри одного модуля (→ чистота), несоответствие
кода тексту ADR (→ код↔документация; но нарушение **правила слоёв**,
записанного в ADR, — твоё: ты проверяешь структуру, они — текст).

## Чек-лист

- Направление зависимостей: `honestml.core` не импортирует ни внешние слои, ни
  frame/ML-библиотеки; зависимости идут внутрь (composition → application →
  adapters → core). Нарушения ищи от фактов фазы 0 (контракты импортов) и
  подтверждай чтением.
- Циклы между модулями; «бутылочные горлышки» — модуль, от которого зависит
  всё и который зависит от всего.
- Утечка деталей через границу: конкретные фреймы (polars/pandas),
  sklearn-эстиматоры, объекты Optuna в сигнатурах `core` и `application`.
- Логика не на своём слое: доменные правила (политика выбора, гейты, пороги)
  внутри адаптеров или композиции, которым по конвенции положено переводить и
  связывать, а не решать.
- Обходы портов: использование конкретного адаптера там, где объявлен порт;
  вторая точка интеграции с той же библиотекой мимо существующего адаптера.
- Новый доменный модуль, не заведённый в свой контракт `.importlinter`:
  правило, которое никто не проверяет, — не правило.
- Контракты публичных границ: публичный API, формат `ModelArtifact` и манифеста,
  плагин-контракт — изменение без версии и пути миграции.

## FP-контракт

**Жёсткие исключения**: вкусовые предпочтения по структуре каталогов;
«я бы разбил этот модуль» без нарушенного правила; паттерн ради паттерна
(предлагать абстракцию там, где нет двух реализаций).

**Прецеденты**: composition root имеет право знать всё — связывание
зависимостей в точке входа не нарушение; разрешённое действующими контрактами
`.importlinter` — закон проекта, не повод для находки; переходные дублирующие
пайплайны, помеченные как миграция, — TRADE-OFF.

## Доказательства

Каждая находка цитирует **нарушенное правило** (строка инварианта/ADR/контракта —
правило, которое можешь процитировать дословно) + импорт/вызов, который его
нарушает. Нет цитируемого правила — это предложение по улучшению (Info),
не нарушение.
