# Направление: Незавершённая разработка

## Чартер

Инвентаризирует **недостроенное**: TODO/FIXME/HACK, заглушки, фиче-флаги,
зомби-код, начатые-но-брошенные механизмы. Ценность — не сырой список (его
даёт grep из фазы 0), а **классификация**: что из этого долг, что план,
что мусор. Не твоё: баг в работающем коде (→ корректность), мёртвый код без
признаков «недостроя» (→ чистота).

**Два режима — отрабатывай только заданный чартером:** *локально* (по сегменту)
— TODO/заглушки внутри него; *сквозной проход* — артефакт определён, но нигде не
потребляется (мёртвый флаг/таблица/событие): нужен grep по всему репозиторию.

## Классификация — каждому артефакту один из бакетов

Для каждого найденного TODO/заглушки/флага ответь на два вопроса:
**есть потребители?** (вызывается/включается ли) и **есть владелец/план?**
(ссылка на задачу, ADR, дату, понятное намерение):

| Потребители | План | Бакет | Действие в roadmap |
|---|---|---|---|
| да | да | **в работе** | Info: убедиться, что план жив (дата не протухла) |
| да | нет | **зомби** | High/Medium: код работает, но никто не отвечает — тихий долг |
| нет | да | **отложено** | Low: пометить сроком или закрыть план |
| нет | нет | **мусор** | Medium: удалить (подтвердив мёртвость) |

## Чек-лист

- TODO/FIXME/HACK/XXX из среза фазы 0: возраст (git blame), есть ли ссылка на
  задачу, не описывает ли давно сделанное.
- Заглушки и стабы: `pass`/`NotImplementedError`/возврат константы на
  **достижимом** пути; заглушка на заявленном рабочим пути — отдай
  корректности, твоя — заглушка с намерением «допилить».
- Фиче-флаги: инвентаризируй все; для каждого — состояние по умолчанию, есть
  ли путь включения, жив ли план (флаг, выключенный годами без плана, — зомби;
  но см. прецеденты).
- Половинные механизмы: поле манифеста, которое никто не читает, конфиг-опция
  без единого потребителя, компонент, зарегистрированный, но недостижимый в
  выборе, порт с единственной заглушечной реализацией «на потом».
- Тестовые пропуски: skip/xfail с протухшей причиной.

## FP-контракт

**Жёсткие исключения**: TODO в тестовых фикстурах/примерах; флаги фреймворков
и библиотек (не проекта); недавние артефакты (моложе ~2 недель) текущей
работы — это WIP, не долг.

**Прецеденты**: опции, выключенные по умолчанию с задокументированным планом
(«OFF до эмпирической проверки на реальных датасетах»), — «в работе», не зомби,
пока план не протух; порт с одной реализацией, предусмотренный принятым
дизайном, — не половинный механизм. Прецеденты проекта — из profile.md.

## Доказательства

Каждая находка: артефакт (`file:line` + цитата), возраст (git), бакет
с ответами на оба вопроса. «Флаг мёртв» требует grep-следа: где определён,
где читается, что его не включает.
