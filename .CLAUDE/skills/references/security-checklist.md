# Security & Safety Checklist (HonestML)

Поверхность узкая: сети, БД, аутентификации и секретов в рантайме нет.
Цена ошибки — исполнение чужого кода при загрузке артефакта и данные, утёкшие в
артефакт, отчёт или логи. Проверяй в Review изменений на границах ввода-вывода — до
коммита фазы. Дополняет ADR-0067 (целостность артефакта) и `docs/plugin-contract.md`.

## Десериализация артефакта (наивысший риск)
- [ ] Порядок загрузки не нарушен: version-gate → проверка контрольных сумм →
      dispatch по `model_type` → `joblib.load`; решения по телу модели — после verify.
- [ ] Имена файлов из манифеста берутся как basename: ни разделителей, ни `..`, ни
      абсолютных путей — чтение только из каталога артефакта.
- [ ] Новый файл артефакта попадает в `checksums.files`, иначе его не проверяет ничто;
      несовпадение суммы даёт `ArtifactIntegrityError`, а не WARNING и продолжение.
- [ ] Граница доверия названа честно: checksum ловит порчу и наивную подмену, но не
      подлинность — pickle остаётся исполнением кода.

## Плагин-контракт (исполнение стороннего кода)
- [ ] Discovery по entry-points `honestml.models` импортирует код чужого пакета;
      новые точки расширения добавляются осознанно, а не «заодно».
- [ ] Дескриптор валидируется на регистрации; конфликт имён — `PluginConflictError`,
      а не тихая победа одного из компонентов.
- [ ] Отказ стороннего компонента изолирован и не роняет прогон целиком.

## Входные пути и внешние данные
- [ ] Файлы читаются только через границу загрузки: whitelist `.parquet`/`.csv`,
      перечисление верхнего уровня каталога, без склейки путей из сырых строк.
- [ ] Значения из манифеста и конфига, попадающие в вызовы sklearn (режим усреднения,
      имя метрики), валидируются на границе: манифест — внешний вход.

## Утечка данных в артефакт, отчёт и логи
- [ ] Схема хранит фактические значения категорий train — ни одна новая сущность не
      тащит в `schema.json`/`manifest.json` сырые данные сверх необходимого.
- [ ] `run_report.json` и рендер отчёта несут агрегаты, метрики и резолвнутый конфиг,
      а не строки датасета; HTML-рендер экранирует всё, что пришло из данных.
- [ ] Логи называют колонку и причину, а не печатают её значения; трекинг не уносит
      признаки и чувствительные части путей в параметры и теги.
- [ ] Токенов и ключей нет в коде, ноутбуках и git-истории; `.env` в `.gitignore`.

## Зависимости и extras
- [ ] Версии запинены lock-файлом; новая зависимость оправдана и из доверенного
      источника.
- [ ] Extras остаются опциональными: импорт ленивый, отсутствие extra даёт
      `MissingDependencyError`, а не падение внутри пайплайна.
- [ ] Новый обязательный импорт не появляется скрытно: то, чего нет в `[dev]`, в
      тестах стоит под `pytest.importorskip`.
